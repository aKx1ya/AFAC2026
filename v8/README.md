## 动机
capital_intention 占 Task2 一半，但阈值从 v2 起就没系统调过。离线验证发现它跌市偏弱（普跌日买入召回仅 0.12）。

## 离线验证（防 v6/v7 式无效提交）
用 `_intent_harness.py`：42 天扩展数据（0506–0703）、未来8日方向**双口径**代理真值（绝对方向 + 市场中性化）、时间切分 train/test、分普涨/震荡/普跌。

**上线判据**：仅当 **两种真值口径 × held-out 测试集 × 各行情均非负** 才上线。结果：

| 口径 | 测试集净增益 | 最差行情 | 普跌日 |
|---|---|---|---|
| 绝对方向 | +0.0055 ✓ | +0.0052 ✓ | +0.0067 |
| 市场中性 | +0.0057 ✓ | +0.0019 ✓ | +0.0151 |

对比：纯阈值网格（单口径 +0.0069）与鲁棒偏科候选均**未通过**双口径门槛，已被否决——只有这个最小双杠杆组合稳健通过。

## 关键发现（写入 CHANGELOG）
原始 proxy 被**市场 beta 污染**：样本期整体净跌（未来8日中位 -3.7%），绝对方向真值系统性偏"卖出"（54%），把超跌反弹也标成卖出——这是普跌日买入召回低的部分原因。故引入市场中性化口径做双重验证。
