# v5 — Task1 聚类空间提纯（在 v4=0.5690 基础上）

**待评测**（评测日 20260701 已跑通打包）。**只改 Task1，Task2 与 v4 完全一致**（已 diff 验证 `predict_result.csv` 逐行相同）。

## 为什么只动 Task1
Task1 占 40% 且评分看聚类质量（轮廓/CH/Wasserstein/DTW）。诊断发现 v4 用 21 维做 KMeans 距离聚类，其中混入了**为 Task2 设计的稀疏 0/1 证据信号**（连板/封板/龙虎榜/机构席位）——这些在距离聚类里是噪声，稀释了连续行为维度的可分性。

## v5 的三处改动
1. **聚类空间提纯**：聚类只用 **14 维连续判别特征**（资金结构/换手/价格/筹码/攻击性），剔除稀疏二值证据。语义标签匹配仍用完整画像（含证据列），互不影响。
2. **证据型标签加门槛**：`机构资金调仓` 需簇内真有机构席位痕迹（`inst_signal≥0.10` 或 `on_top_list≥0.20`）才可分配——否则 greedy 唯一分配会把它硬塞给一个 `inst=0` 的大簇，语义失真、损可解释性评分。
3. **补充 `获利盘活跃换手` 标签**：孤儿簇不再回退到通用标签，而是从「过闸且未用」的候选里取最高分，标签更贴合。
