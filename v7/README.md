# v7 — Task1 每股定制化解释（在 v5=0.5906 基础上）

**待评测**（评测日 20260701 已跑通打包）。**只改 `pattern_explanation`**——`pattern_type`、聚类过程、Task2 全部与 v5 逐行相同（已 diff 验证）。

## 动机
赛题 Task1 明确「通过标签的**合理性和可解释性**打分」。但 v2~v6 的 `pattern_explanation` 是**同一 pattern 下所有股票共用一句模板**（如所有"游资抢筹拉升"股都写同一句），可解释性弱。v7 改为**逐股定制、引用该股当日真实数字**。

## 方法
`build_explanation()` 按固定结构拼接该股当日事实 + 研判结论：
1. **价格/封板**：涨停(N连板)/跌停/触板回落/涨跌幅
2. **换手量能**：换手率、放量/缩量(量比)、振幅
3. **资金结构+净流向**：大单主导/小单为主/中单活跃、净流入/流出(%)
4. **硬证据**：量化游资席位/机构专用席位/游资明细N家/登龙虎榜
5. **获利盘/成本**：获利盘高/套牢盘重(winner_rate)
6. **研判结论**：该 pattern 的语义判定

示例：
```
600076: 收盘涨停(2连板)，换手1.9%、缩量(量比0.6)、振幅6.9%，大单主导、
        资金净流出(-2.4%)；研判为游资短线抢筹拉升
600172: 下跌-2.4%，换手15.9%、缩量(量比0.7)、振幅10.3%，中单活跃、
        资金净流出(-4.2%)；研判为游资派发出货
```
